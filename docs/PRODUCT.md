# FootballTerror — Product Definition

## Overview

FootballTerror is an autonomous football intelligence platform. Its core loop is:

**OBSERVE → NORMALIZE → ANALYZE → FORECAST → PREDICT → EXPLAIN → PUBLISH → EVALUATE → LEARN**

FootballTerror is NOT primarily a news site. It continuously processes structured football data and credible public information, derives proprietary intelligence, runs numerical models and specialist AI agents, and presents the resulting intelligence through multiple surfaces.

## Core Principle

Never use an LLM to invent numerical football data. Numerical values must originate from structured source data, deterministic calculations, statistical models, ML models, or validated forecast models. LLMs may interpret, challenge, contextualize and explain numerical outputs.

Every published factual claim must maintain provenance wherever technically possible.

## Target Competition

Premier League is the first target competition.

## Flagship Club

Liverpool FC is the first and flagship club implementation.

## Key Product Surfaces

| Surface | Description |
|---------|-------------|
| War Room | Homepage: "What's worth knowing in football right now?" |
| Match Room | Per-match intelligence: preview, live, autopsy |
| Power Index | Auditable team strength ranking (0-100) |
| Terror Index | Match significance/intensity (0-100) |
| Terror Vision | AI-generated visual intelligence |
| Club Intelligence | Deep club-level analysis pages |
| Model Performance | Public prediction tracking and honesty |
| Personalized Alerts | User-followed team/match notifications |

## Lifecycle States

Matches progress through states on the same URL:
- **PREVIEW** — Pre-match intelligence
- **BATTLE_MODE / LINEUPS** — Lineups confirmed
- **LIVE** — In-play intelligence
- **AUTOPSY / POST_MATCH** — Post-match analysis and evaluation
